# My WhatsApp Bot

Simple WhatsApp bot with basic commands.

## Commands
- `!ping` - Check bot status
- `!hello` - Say hello
- `!time` - Get current time
- `!help` - Show all commands
- `!sticker` - Convert image to sticker

## Run Locally

```bash
npm install
node index.js
